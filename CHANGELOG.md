# Changelog

All notable changes to Client-Generator will be documented in this file.

## [1.0.0] - 2026-09-03

### Added

#### Initial Release Features

- **Framework Choice**: Support for Next.js (full-stack) and Vite (SPA)
- **Interactive CLI**: User-friendly questionnaire for project setup
- **Modular Architecture**: Feature-based module structure with feature gates (Next.js only)
- **Component System**: Unified component organization across frameworks
  - shadcn/ui integration
  - Tailwind CSS 4.0.0
  - Storybook with auto-discovery of .stories.tsx files
  
- **State Management**: Production-ready setup
  - Zustand 5.0.0 for client state
  - Immer 10.0.0 for immutable updates
  - Global store for app-wide state
  - Per-module stores for isolated state
  
- **Form Handling**: Modern form patterns
  - react-hook-form 7.48.0
  - Zod 4.4.0 for runtime validation
  - Integration examples
  
- **API Integration**: .NET backend connectivity
  - Axios client with interceptors
  - Automatic JWT token injection
  - 401 error handling
  - Configurable backend URL
  
- **Development Tools**:
  - TypeScript 5.5.2 (strict mode)
  - ESLint configuration
  - Prettier formatting
  - Husky pre-commit hooks
  - Vitest for unit testing
  - Playwright for E2E testing
  
- **Documentation**:
  - Comprehensive README
  - Development guide
  - Generated project includes inline documentation
  - Feature gate explanations
  - Store management guide
  
- **Project Generation**:
  - Creates project structure automatically
  - Sets up all dependencies
  - Configures environment files
  - Initializes git repository (optional)
  - Installs dependencies (optional)

## Migration Guide

### Migrating Existing Projects to Use Generated Template

If you have existing projects and want to adopt the Client-Generator structure:

1. Use `client-generator` to create a new project with identical settings
2. Copy your code into the new project structure
3. Update imports to match new structure
4. Test thoroughly
